Enhance the existing smart home mobile UI design by applying modern visual improvements while preserving the current layout structure, color palette, and navigation system.

Do not redesign the entire interface. Instead, refine the current design to make it look more modern, polished, and consistent with contemporary smart home applications.

---

VISUAL MODERNIZATION

Improve the visual style of the interface while keeping the existing theme.

Apply the following visual enhancements:

Accent Color States
Devices that are active should visually stand out.

Active device tiles should:

* use the accent color for the icon
* have a subtle tinted background using the accent color
* include a small visual indicator showing the device is active

Inactive devices should:

* use neutral gray icons
* have a neutral background
* appear visually quieter.

---

SOFT COLOR GRADIENTS

Replace flat accent colors with subtle gradients.

Example gradient style:

* primary accent color transitioning to a slightly darker shade
* soft and minimal, not overly saturated

Gradients can be applied to:

* active device tiles
* primary action buttons
* highlights within the interface.

---

IMPROVED TYPOGRAPHY HIERARCHY

Improve readability and visual hierarchy by adjusting text styles.

Device cards should use the following structure:

Device Name
Medium or semibold weight.

Primary Status
Regular weight text showing key device information.

Secondary Status
Smaller, muted text with additional details.

Example structure inside a tile:

Lamp
Warm White • 70%

or

Air Conditioner
22°C • Cooling

---

CONSISTENT MINIMALIST ICONS

Ensure all icons follow a consistent minimalist line icon style.

Icon rules:

* outline icons
* uniform stroke width
* monochrome or accent color
* modern smart home design style.

Replace any remaining emojis with these icons.

---

IMPROVED CARD DESIGN

Device tiles should appear as modern cards with depth.

Apply:

* rounded corners (18–22px)
* subtle elevation shadows
* consistent padding

Example shadow style:

soft elevation with low opacity shadow to separate tiles from the background.

---

SPACING AND WHITESPACE

Increase whitespace to create a cleaner layout.

Recommended spacing adjustments:

* card padding around content: 16–20px
* grid spacing between tiles: 16px
* section spacing: 24px

This should create a less crowded and more premium interface.

---

MICRO-INTERACTIONS (VISUAL HINTS)

Design the interface with subtle interaction feedback.

Examples:

* device tiles slightly scale down when tapped
* state changes animate smoothly
* color transitions fade smoothly.

Animations should feel fast and subtle (around 150–250ms).

---

PROFILE SCREEN — ENERGY CONSUMPTION

Extend the Profile section by adding a new area dedicated to energy usage analytics.

Add a new section titled:

Energy Consumption

This section allows the user to view energy usage statistics.

---

ENERGY USAGE OVERVIEW

At the top of the section display summary statistics such as:

Today's Energy Usage
Weekly Energy Usage
Monthly Energy Usage

These can be displayed as small statistic cards showing:

* total energy used
* units such as kWh
* a small trend indicator or icon.

Example layout:

Energy Consumption

Today
12.5 kWh

This Week
84.2 kWh

This Month
320.4 kWh

---

ENERGY CHARTS

Include simple charts to visualize consumption trends.

Suggested charts:

Daily consumption chart
Weekly consumption chart
Monthly consumption chart

Charts should be clean and minimal.

---

DEVICE ENERGY BREAKDOWN

Below the overview, display a list or card grid showing how much energy each device consumes.

Each device card should include:

Device icon
Device name
Energy usage amount

Example:

Lamp
3.2 kWh this week

Air Conditioner
24.7 kWh this week

Refrigerator
41.5 kWh this week

Speaker
1.1 kWh this week

---

DEVICE ENERGY VISUALIZATION

Optionally include a simple visualization such as:

* horizontal progress bars
* percentage indicators
* pie chart showing which devices consume the most energy.

---

DESIGN CONSISTENCY

Ensure that the new Energy Consumption section uses the same:

* typography
* icon style
* card design
* spacing
* color palette

as the rest of the application.

The final result should feel like a natural extension of the existing smart home UI, not a separate design.
